# Cryptocurrency Price Tracker

A Python-based web scraping project that collects cryptocurrency price data from CoinMarketCap using Selenium.

## Technologies Used

- Python
- Selenium
- Pandas
- WebDriver Manager
- CoinMarketCap

## Features

- Collects cryptocurrency data
- Extracts top cryptocurrency details
- Stores data in CSV format
- Displays the collected data

## Output

The scraped cryptocurrency data is saved as:

crypto_prices.csv
